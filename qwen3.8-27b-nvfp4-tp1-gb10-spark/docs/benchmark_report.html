Qwen3.8-27B-NVFP4（unsloth）DGX Spark（GB10）单机 TP1 压测报告

基于 vLLM 官方基准工具 vllm bench serve 的部分矩阵测试。指标名称、单位与工具官方输出保持一致。

报告日期：2026-09-02 硬件：DGX Spark（GB10，SM121，121G 统一内存） 模型：unsloth/Qwen3.8-27B-NVFP4（TP=1，MTP=3） vLLM nightly 0.28.1rc1.dev283 范围：3 组 9 档（部分矩阵）

1. 测试结论

测试档位
9/9 全部成功

3 组输入/输出组合 × 并发 1/2/4，零失败

单流 decode
17–24 tok/s

TPOT 41–58 ms

并发 4 聚合吞吐
58.6–76.4 tok/s

1K/4K/8K 组并发 4 档

MTP 接受率
38.7–70.8%

接受长度 2.16–3.12

  • unsloth 包（compressed-tensors 量化）在 SM121 上走 FlashInfer CuteDSL NVFP4 kernel（无原生 FP4 计算单元，weight-only 路径），TPOT 41–58 ms，decode 为主短板；TTFT 0.69–18.11 s。
  • 该 kernel 路径的连带特征：KV cache 池 50.33 GiB（容量 1,420,556 tokens，256K 满长并发约 5.42 路）；首次启动 autotune 极慢（每 profile ~11s，全程约 8~9 分钟），需 VLLM_ENGINE_READY_TIMEOUT_S=3600 才能完成首次启动（结果进 cache 后恢复正常）。

2. 部署环境与服务配置

项目配置
硬件DGX Spark（NVIDIA GB10，SM121，121G 统一内存；nvidia-smi 不报显存数字，以下为启动日志口径）
显存拆分（启动日志）权重 22.47 GiB（含 MTP 头）+ KV cache 50.33 GiB + 其余为峰值激活/workspace 与 CUDA graph
KV cache 容量1,420,556 tokens（256K 满长并发上限约 5.42 路）；KV dtype fp8_e4m3（checkpoint 自带）
推理框架vLLM 0.28.1rc1.dev283+g300f68832（nightly，venv ~/vllm，Rust frontend）
模型unsloth/Qwen3.8-27B-NVFP4（quantization=compressed-tensors），served name Qwen3.8-27B
kernel 路径FlashInferCuteDslNvFp4W4A16（NVFP4 GEMM）+ FLASHINFER attention（xqa decode）
API端口 8123（OpenAI 兼容接口），max_model_len=262144
启动要点首次启动必须 export VLLM_ENGINE_READY_TIMEOUT_S=3600（CuteDSL autotune 约 8~9 分钟，默认 600s 超时会导致启动失败）；autotune 结果进 flashinfer cache 后，后续启动恢复正常

启动命令

export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_DISABLE_XET=1
export VLLM_WORKER_MULTIPROC_METHOD=spawn
export CUDA_VISIBLE_DEVICES=0
export VLLM_USE_RUST_FRONTEND=1
export VLLM_ENGINE_READY_TIMEOUT_S=3600

vllm serve unsloth/Qwen3.8-27B-NVFP4 \
  --served-model-name Qwen3.8-27B \
  --trust-remote-code \
  --tensor-parallel-size 1 \
  --host 0.0.0.0 --port 8123 \
  --gpu-memory-utilization 0.95 \
  --max-model-len 262144 \
  --max-num-batched-tokens 32768 \
  --enable-chunked-prefill \
  --async-scheduling \
  --enable-prefix-caching \
  --speculative-config '{"method":"mtp","num_speculative_tokens":3}' \
  --load-format fastsafetensors \
  --reasoning-parser qwen3 \
  --tool-call-parser qwen3_coder \
  --enable-auto-tool-choice \
  --api-key <内网约定>

5. 数据边界与备注

  • 测试范围：仅 1K→1K、4K→4K、8K→8K × 并发 1/2/4；4K→32K、8K→32K 两组及 16/32/64 高并发档未测试（部分矩阵）。
  • KV cache 为 fp8_e4m3（checkpoint 自带）；KV 池 50.33 GiB。
  • prefix caching 虽开启但被 MTP+Mamba 架构自动禁用（跨请求前缀复用不可用）。
  • 首次启动需调大引擎就绪超时（autotune 约 8~9 分钟）；结果进 flashinfer autotune cache 后恢复正常。
  • 原始数据：压测机本地 /root/qwen27b-bench/results-spark44-qwen38/（9 个 JSON + 逐档 log）。
