9. 数据边界与备注

  • 范围：29 档完整矩阵（1K×8 并发档 / 4K×6 / 8K×6 / 32K×5 / 64K×4）+ c1 双跑冷启动保护取热值（后跑）；本腿矩阵时窗 13:58–15:00 UTC
  • 引擎健康检查：每档后 /health 探测 + boot 日志错误扫描，全程零异常；全部档失败请求数为 0（30 个 bench 块全绿）
  • 接受率口径：矩阵表内为 vllm bench serve 单档窗口 Σ（接受率 % / 接受长 / 逐位 %）；服务端窗口 Σ 见下表。注：vllm bench serve 默认不再设置 temperature=0（由服务端默认采样决定），MTP 接受率逐跑存在方差——单流中低带吞吐受此影响，正式对照建议补 temperature=0 腿
  • 本腿每档 boot 一次（k5 与无投机分别 boot），BOOT CMD 见环境节；c1 双跑首跑为冷启动腿
  • 原始数据：本地 data/glm-matrix-155/（矩阵/boot/spec 窗口日志 + tiers.tsv + acceptance_k5.tsv）；llm-test glm53-flash-pro6000-sm120/logs/matrix-155/
