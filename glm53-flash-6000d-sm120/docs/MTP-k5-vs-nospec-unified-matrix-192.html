9. 数据边界与备注

  • 范围：两腿各 29 档完整矩阵（1K×8 / 4K×6 / 8K×6 / 32K×5 / 64K×4）+ c1 双跑冷启动保护取热值（后跑）；两腿零失败（60 个 bench 块全绿）
  • 读法：每长度组内两行=同档两腿并列（c MTP k5 / c 无投机），接受率列仅 MTP 腿有值
  • 同机结论：4K 起 k5 单流全面领先（64K c1 315.5 vs 87.6=3.60x；64K c8 843.4 vs 408.9=2.06x）；1K 带 c32 起无投机反超（c128 1713.1 vs 1216.4）——短输入高并发草稿开销大于收益
  • 引擎健康检查：每档后 /health 探测 + boot 日志错误扫描，全程零异常；全部档失败请求数为 0
  • 接受率方差注：vllm bench serve 默认不再设置 temperature=0（服务端默认采样），MTP 接受率逐跑存在方差——单流中低带受此影响，正式对照建议补 temperature=0 腿
  • 本机为该环境首次部署：首 boot 含 FlashInfer JIT/autotune 预热（驱动脚本 health 窗已扩至 400×10s）
  • 原始数据：本地 data/glm-matrix-192/（两腿矩阵/boot/spec 窗口日志 + tiers.tsv + acceptance_k5.tsv）；llm-test glm53-flash-6000d-sm120/logs/matrix-192/；单腿版报告见本目录另两份
