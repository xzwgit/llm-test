9. 数据边界与备注

  • 测试范围：random 6 档 × 3 k 值 + Agent 3 session × 3 k 值 = 18 random 档 + 9 Agent session，全零失败。
  • 84G 卡 KV 池比 96G(.180) 紧一半：单流 1M 可用，1M 并发约 2-3 路（.180 为 5-8 路）。
  • k=3 Agent 有 1 轮 raw XML 泄漏（<tool_call> 原文），k=4/5 无此现象。
  • Agent 场景推荐 k=4（延迟最优 + 零异常）；random 吞吐在低并发 k=5 更快、高并发 k=3 更快、中并发 k=4 均衡。
  • 本报告全部数据走 /v1/completions + /v1/chat/completions（Agent），在 #62535 修复后的 FULL cudagraph 下采集。
  • 原始数据：.158 /root/test_ops/k_ab.log（18 档官方输出全量）+ agent_k*_results.jsonl + agent_k*_spec_metrics.log。
