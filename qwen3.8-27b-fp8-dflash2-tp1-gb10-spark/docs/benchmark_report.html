Qwen3.8-27B-FP8 + DFlash2（投机解码）DGX Spark（GB10）单机 TP1 压测报告

基于 vLLM 官方基准工具 vllm bench serve 的部分矩阵测试。指标名称、单位与工具官方输出保持一致。

报告日期：2026-09-03 硬件：DGX Spark（GB10，SM121，121G 统一内存） 模型：Qwen3.8-27B-FP8（TP=1，DFlash2 num_spec=7） vLLM nightly 0.28.1rc1.dev283 范围：3 组 9 档（部分矩阵）

1. 测试结论

测试档位
9/9 全部成功

3 组输入/输出组合 × 并发 1/2/4，零失败

单流 decode
9.9–17.7 tok/s

TPOT 56–111 ms

并发 4 聚合吞吐
33.0–44.0 tok/s

1K/4K/8K 组并发 4 档

DFlash2 接受率
13.7–30.2%

接受长度 1.96–3.11（num_spec=7）

  • DFlash2 draft 深度为 7（本版 vLLM 0.28.1rc1 支持深度 7 启动）；随机 token 数据集下接受率 13.7~30.2%、平均接受长度 1.96~3.11——深度 7 的后段 draft 大量被拒，验证开销显著（4K 组 TPOT 达 89~111 ms）。
  • 主模型为官方 FP8 包（KV cache bf16，容量 1,014,183 tokens）；GEMM 走 CutlassFp8BlockScaled kernel。

2. 部署环境与服务配置

项目配置
硬件DGX Spark（NVIDIA GB10，SM121，121G 统一内存；nvidia-smi 不报显存数字，以下为启动日志口径）
模型Qwen3.8-27B-FP8（本地权重目录），served name Qwen3.8-27B
投机解码--speculative-config {"method":"dflash","model":"incoai/Qwen3.8-27B-DFlash2","num_speculative_tokens":7}
KV cachebf16（checkpoint 自带，未量化），容量 1,014,183 tokens（256K 满长并发上限约 3.87 路）
kernel 路径CutlassFp8BlockScaled（FP8 GEMM）+ FlashAttention（attention 后端）
推理框架vLLM 0.28.1rc1.dev283+g300f68832（nightly，venv ~/vllm，Rust frontend）
API端口 8123（OpenAI 兼容接口），max_model_len=262144

启动命令

export HF_ENDPOINT=https://hf-mirror.com
export HF_HUB_DISABLE_XET=1
export VLLM_WORKER_MULTIPROC_METHOD=spawn
export CUDA_VISIBLE_DEVICES=0
export VLLM_USE_RUST_FRONTEND=1
export VLLM_ENGINE_READY_TIMEOUT_S=3600

vllm serve /home/nvidia/Qwen3.8-27B-FP8 \
  --served-model-name Qwen3.8-27B \
  --trust-remote-code \
  --tensor-parallel-size 1 \
  --gpu-memory-utilization 0.95 \
  --max-model-len 262144 \
  --max-num-batched-tokens 32768 \
  --enable-chunked-prefill \
  --async-scheduling \
  --enable-prefix-caching \
  --speculative-config '{"method":"dflash","model":"incoai/Qwen3.8-27B-DFlash2","num_speculative_tokens":7}' \
  --load-format fastsafetensors \
  --reasoning-parser qwen3 \
  --tool-call-parser qwen3_coder \
  --enable-auto-tool-choice \
  --host 0.0.0.0 --port 8123 \
  --api-key <内网约定>

5. 数据边界与备注

  • 测试范围：仅 1K→1K、4K→4K、8K→8K × 并发 1/2/4（部分矩阵）；4K→32K、8K→32K 及 16/32/64 高并发档未测。
  • 本配置为 Qwen3.8-27B-FP8 主模型 + DFlash2 draft（深度 7）；KV cache bf16 为 checkpoint 自带行为。
  • prefix caching 虽开启但被投机解码 + Mamba 架构自动禁用。
  • 测试数据为 random 数据集随机 token；并发为 burst 全同时发出。
  • 原始数据：压测机本地 /root/qwen27b-bench/results-spark44-dflash7-fp8/（9 个 JSON + 逐档 log）。
